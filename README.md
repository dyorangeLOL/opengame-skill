# OpenGame Skill

一个参考 [OpenGame](https://github.com/leigest519/OpenGame) 整理的 Codex skill，用于创建、改进和调试可玩的网页游戏。

本项目由 Lily 整理，基于 OpenGame 项目的公开资料和游戏开发流程改编，并非 OpenGame 官方发布。原项目由 [leigest519/OpenGame](https://github.com/leigest519/OpenGame) 发布，原项目采用 Apache License 2.0。感谢原项目作者及贡献者。

## 内容

- `opengame/SKILL.md`：游戏开发和验证工作流程。
- `opengame/references/opengame.md`：原项目结构、五种游戏类型和调试要点。

本仓库不包含 OpenGame 的运行程序、模型或游戏模板；使用这些组件请参考原项目。

## 安装

将 `opengame` 文件夹复制到 Codex 的 skills 目录（通常为 `~/.codex/skills/`），之后可使用 `$opengame` 调用。Windows 用户可将其复制到 `%USERPROFILE%\.codex\skills\opengame`。

例如：`使用 $opengame 制作一个键盘操控的贪吃蛇网页游戏。`
